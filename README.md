# 🛒 Blinkit Sales Analysis Using Python

**Exploratory Data Analysis | Python | Pandas | NumPy | Matplotlib | Seaborn**

An end-to-end exploratory data analysis project focused on understanding **Blinkit's sales performance**, product categories, outlet characteristics, and location-based trends using Python.

---

## 📌 Overview

The goal of this project is to transform raw Blinkit sales data into meaningful business insights through **data cleaning, exploratory analysis, KPI calculation, and visualization**.

The analysis focuses on understanding what drives sales performance across different products, outlet types, outlet sizes, locations, and fat-content categories.

This project demonstrates a practical data analyst workflow:

> **Data Exploration → Data Cleaning → Analysis → Visualization → Business Insights**

---

## 🎯 Business Objectives

The analysis was performed to answer key business questions such as:

- Which **product categories** generate the highest sales?
- How do sales differ between **Low Fat** and **Regular** products?
- Which **outlet locations** contribute the most to overall sales?
- Does **outlet size** have an impact on sales?
- How does sales performance vary based on **outlet establishment year**?
- Which product categories are performing strongly?
- What patterns can be identified from the available sales data?

---

## 🗂️ Dataset

The dataset contains information about Blinkit products, sales, ratings, and outlet characteristics.

| Feature | Description |
|---|---|
| **Item Identifier** | Unique identifier for each product |
| **Item Fat Content** | Fat-content classification of the product |
| **Item Type** | Category/type of the product |
| **Sales** | Sales generated by the product |
| **Rating** | Customer/product rating |
| **Outlet Size** | Size classification of the outlet |
| **Outlet Location Type** | Location tier of the outlet |
| **Outlet Establishment Year** | Year the outlet was established |

## 🧹 Data Preparation

Before performing the analysis, the dataset was explored and prepared to ensure reliable results. The workflow included:

- Inspecting the dataset structure
- Checking data types
- Identifying unique values
- Examining categorical variables
- Identifying inconsistent category labels
- Standardizing categorical values
- Preparing the dataset for analysis

### Example: Category Standardization

The **"Item Fat Content"** column contained multiple representations of the same categories, such as:

`LF`, `low fat`, `Low Fat`, `reg`, `Regular`

These values were standardized into consistent categories to prevent incorrect grouping during analysis.

## 📊 Key Performance Indicators

The analysis calculates important sales KPIs including:

- **Total Sales** — Measures the overall sales generated across the dataset
- **Average Sales** — Represents the average sales value per item
- **Number of Items** — Measures the number of product records analyzed
- **Average Rating** — Provides an overall view of product/customer ratings

These KPIs provide a high-level understanding of the dataset before performing deeper analysis.

## 🔍 Exploratory Data Analysis

The project uses multiple visualizations to investigate sales patterns.

### Sales by Fat Content
Compares sales generated by **Low Fat** and **Regular** products to understand whether fat content is associated with differences in sales performance.

### Sales by Item Type
Analyzes sales across different product categories to identify **strong and weak-performing segments**.

### Sales by Outlet Location
Compares sales across different outlet location tiers to identify whether geographical classification affects sales performance.

### Sales by Outlet Size
Examines the relationship between **outlet size** and total sales to see whether larger or smaller outlets generate higher sales.

### Sales by Outlet Establishment Year
Analyzes sales performance across different outlet establishment years to investigate how outlet age relates to sales.

### Fat Content Across Outlet Locations
Examines how Low Fat and Regular products perform across different outlet location types, helping identify differences in product preferences by location.
